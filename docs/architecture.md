# РукаХод: структура проекта

Статус: проектное решение для следующего этапа. Текущий `ui/` — первый вариант экрана, без подключения к оборудованию.

## Один репозиторий

```text
rukahod/
  ui/             единый браузерный пульт
  robot/          локальный сервер пульта и адаптеры к ROS 2
  description/    модель ровера и манипулятора, mesh и параметры суставов
  config/         камеры, адреса устройств, лимиты и режимы
  launch/         запуск всей системы
  scripts/        сборка и запуск одной командой
  docs/           контракт и инструкции
```

Папки добавляются по мере реализации. В Git всё живёт и версионируется вместе. Если ROS 2 потребует больше одного `package.xml` для разных типов сборки, эти пакеты останутся внутри этого репозитория.

## Запуск на машине ровера

Один локальный процесс приложения отдаёт собранный `ui/` по HTTP и предоставляет пульту API того же origin. Адаптеры приложения обращаются к ROS 2, MoveIt и драйверам на этой же машине. Отдельный пакет `silverhand_ws_gateway` не нужен. Браузеру всё равно требуется канал команд и телеметрии: предлагается один WebSocket `/api/ws` внутри приложения, без адресов и портов отдельных arm/rover gateway.

Для единственного оператора сервер выдаёт право управления одной активной сессии. Потеря этой сессии или устаревшие команды движения останавливают ровер. Подтверждение аварийного останова приходит от робота, а не выводится из нажатия кнопки.

Два видеопотока: фронтальная камера и камера манипулятора. Их адреса задаются в конфигурации сервера; браузер получает конфигурацию вместе со страницей. Жёстко прописанные IP и старые третьи камеры в текущем прототипе подлежат удалению при подключении API.

## Границы первого этапа

Пока используется старая геометрия для просмотра компоновки. Новую модель руки и её точные лимиты ждём от владельца проекта. Аппаратные команды не включаются до сверки имён суставов, диапазонов и поведения остановки.

Текущий `ui/src/transport` и `ui/src/rover/transport` содержат старые клиентские реализации и являются исходным материалом для объединения, а не готовым API РукаХода.
