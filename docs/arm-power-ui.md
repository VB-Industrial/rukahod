# Компонент питания руки

`ui/src/components/ArmPowerControl.tsx` подготовлен для настольной и мобильной
версий. На страницах пока не размещён. Подключение:

```tsx
<ArmPowerControl
  state={armPowerState} // "on" | "off" | "unknown"
  available={powerControlAvailable}
  onSetPower={setArmPower} // (enabled: boolean) => Promise<void>
/>
```

Состояние должно приходить от управления реле, а не из факта наличия WS руки
или её heartbeat. Управление питанием должно идти через rover gateway,
доступный и при выключенной руке. Наличие WS ровера само по себе не доказывает
наличие сервиса управления реле: `available` должен учитывать его готовность.

Пока контракт обратной связи релейного модуля не подтверждён, состояние
остаётся `unknown`, кнопка заблокирована. Компонент не подставляет фиктивное
подтверждение питания. `onSetPower` завершается после ответа backend; сам
компонент не меняет показания оптимистически.

Есть RU/EN, состояние ожидания, запрет повторного запроса, сообщение об ошибке
и отдельное подтверждение выключения (снимается удержание приводов). Нет
автоматического включения/выключения при загрузке UI, потере WS или реконнекте.
Фары не затрагиваются. Подключение команды к WS/ROS/реле ещё не реализовано.
