## Что сохранено перед переносом

`~/rukahod-migration-backup-20261019/` содержит локальный Git diff, снимок
калибровки, состояние реле и архив системных настроек. Изменённый файл
калибровки дополнительно сохранён в Git stash `rover2-before-migration`.
При старте руки лимиты заново читаются с её узлов; калибровку первого робота
нельзя считать калибровкой второго.

Скопированный `relay_outputs.state` убран из рабочего пути: состояние реле
другого робота не является достоверным. Управление каналами станет доступно
после известной команды обоим каналам или наблюдения такой команды на Cyphal.
При переносе питание руки и фары не переключаются.

## Обновление

Пакеты собираются из текущего checkout и сабмодуля RUKA2. Перед сборкой
применяется `deploy/topton/patch-cyphal-shutdown.py`. Для запуска ROS
используется `ros-entrypoint.sh` с UDP-профилем Fast DDS и domain 49.
На втором Топтоне Node/npm пока не установлены: UI собран на машине разработки
и перенесён как `ui/dist`. Для сборки непосредственно на Топтоне нужны версии
Node/npm из `ui/package.json` и доступ к npm.

Службы EtherCAN должны повторять запуск и при позднем подключении платы:

```sh
for service in ethernet-can ethernet-can-rover; do
  sudo mkdir -p /etc/systemd/system/$service.service.d
  sudo cp deploy/topton/ethernet-can-retry.conf \
    /etc/systemd/system/$service.service.d/90-retry.conf
done
sudo systemctl daemon-reload
```

Камеры привязаны к USB-портам, не к изменчивым `/dev/videoN`:
`cam1` — USB 3, `cam2` — USB 4 (`video-index2`). При отсутствии камер службы
повторяют запуск. Рука и ровер запускают контроллеры только при готовности
соответствующего оборудования; закрытый WS при отсутствии оборудования штатен.

## Результат проверки переноса

Все 7 ROS-пакетов пересобраны на `brovermax2`; UI перенесён из актуальной
локальной сборки. Проверены контроллер ровера, joint state broadcaster и IMU
broadcaster, HTTP UI, ответ PowerBoard на зелёную индикацию. На отдельном
`vcan_relaytest` пройден тест 100 пересозданий Cyphal-транспорта; проверка
порядка восстановления контроллеров также прошла. Команды движения не подавались.

Во время переноса на CAN подтверждены приводы ровера 1–6, реле 7 и PowerBoard 9.
Обе EtherCAN доступны по своим адресам. Узлы руки 21–26 и USB-камеры пока
не обнаружены; проверка реальной руки, её калибровки и видеопотоков отложена
до появления устройств. Старые калибровка и состояние реле сохранены в backup,
но не используются как подтверждение состояния нового оборудования.
