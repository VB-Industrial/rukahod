# BroverMAX3 — перенос 2026-10-19

Используется схема адресов BroverMAX1. Старая LAN `192.168.22.0/24`
заменена на `10.8.49.0/24` через IPv6 link-local без временного IPv4 alias.
DHCP проверен после применения; незакоммиченных изменений UCI нет.

| Узел | Настройка |
| --- | --- |
| Kroks Rt-Cse G | `10.8.49.254`, serial `014223585548060` |
| Wi-Fi | существующий профиль `BrowerMAX3_5G` сохранён |
| Topton | `brovermax3`, `rosuser`, DHCP-резерв `10.8.49.237` |
| LAN MAC Topton | `00:f0:4d:01:b5:2b` (enp2s0) |
| EtherCAN руки | enp3s0 `10.8.50.1`, плата `10.8.50.2`, MAC `02:e1:e6:e3:a8:48` |
| EtherCAN ровера | enp4s0 `10.8.51.1`, плата `10.8.51.2`, MAC `02:5b:a6:86:07:e7` |
| UI | `http://10.8.49.237:4175/` |
| WS ровера / руки | `8766` / `8765` |

Обе EtherCAN: CAN FD 1000/8000 кбит/с, период 10 мс, UDP плата 1555 / хост 1556,
включены bus0–bus5. Рука отображается в `vcan1.0`–`vcan1.5`, ровер —
в `vcan2.0`–`vcan2.5`. DHCP на выделенных портах выдаёт единственный адрес `.2`
без маршрута по умолчанию. Обе службы EtherCAN включены в автозагрузке,
установлен `ethernet-can-retry.conf` для повторов после потери связи.

## ПО и проверки

Сохранены локальные изменения и системная конфигурация в
`~/rukahod-migration-backup-20261019/`; калибровка также находится в stash
`rover3-before-migration`. Скопированный файл команд реле другого робота
убран из рабочего пути. Начальные команды реле НЕ отправлялись.

Исходники обновлены, все 7 ROS-пакетов пересобраны из checkout и сабмодуля RUKA2.
Применены исправления очистки Cyphal. UI собран на машине разработки и перенесён
в `~/rukahod/ui/dist` (Node/npm на Топтоне не установлены).

Проверены:

- 100 пересозданий Cyphal-транспорта на изолированном `vcan_relaytest`;
- тест порядка восстановления контроллеров и защиты от гонки первого запуска;
- активные `rover_base_controller`, `joint_state_broadcaster`, `imu_sensor_broadcaster`;
- HTTP UI, применение конфигурации EtherCAN, heartbeat приводов ровера 1–6, реле 7 и PowerBoard 9;
- переход PowerBoard LED с жёлтого на зелёный при готовности роверного ПО.

Часы Топтона спешили примерно на 8 часов. Время исправлено при остановленных
контроллерах и записано в RTC; часовой пояс Europe/Moscow, NTP оставлен включённым.
На Kroks время также исправлено. Для автоматической синхронизации и интернета
нужен подключённый WAN; во время настройки WAN был физически отключён.

## Что отложено по указанию оператора

Реле, питание и движение руки не переключать без новой команды оператора.
`rukahod-arm-control` и `rukahod-arm-gateway` остановлены и отключены от
автозагрузки; исходники, пакеты и службы для них установлены. EtherCAN руки
работает независимо. Суставы 21–26 пока не обнаружены; на `vcan1.0` виден
PowerBoard узла 9. Калибровку и лимиты нужно прочитать с реальной руки перед запуском.

Камеры не определяются по USB. Службы `cam1_stream` и `cam2_stream` подготовлены
с автоперезапуском и привязкой к USB-портам как на BroverMAX1.

Телеметрия PowerBoard на `vcan1.0` показывает около 23 В / present=true,
а PowerBoard ровера на `vcan2.1` — около 0.1 В / present=false. Перед проверкой
движения отдельно проверить питание и корректность этих показаний.
Команды движения не подавались.
