# Черновик контракта пульта РукаХод

Статус: схема для реализации, пока без аппаратного подключения. Основана на командах старых arm и rover панелей.

## Соединение

- Страница и API размещены на одном адресе. `GET /api/config` возвращает версию контракта, названия камер и ссылки на их потоки.
- `WS :8765` передаёт команды и состояния руки; `WS :8766` — ровера. На первом этапе сохраняются два старых порта. Каждое сообщение содержит `type`, `seq`, `ts`, `payload`; команды также содержат `command_id`.
- При подключении сервер отправляет полный снимок состояния; затем публикует изменения. В состояниях обязательно указывается время последнего обновления, чтобы UI мог показать устаревшие данные.
- Серверы принимают команды только от одной согласованной операторской сессии. Наблюдатели получают состояние, но не управляют роботом.
- Готовность руки определяется свежим состоянием её контроллера/MoveIt, а не только открытым WebSocket. При отсутствии готовности движения руки недоступны; ровер продолжает работать.

## Команды от пульта

| Область | Команды | Назначение |
| --- | --- | --- |
| Ровер | `cmd_vel`, `stop`, `set_drive_mode`, `set_headlights` | Ручное движение, остановка, режим, свет |
| Манипулятор | `set_joint_goal`, `set_pose_goal`, `plan`, `execute`, `stop` | Цель по суставам или рабочей точке, планирование и движение |
| Система | `estop`, `reset_estop` | Общий аварийный останов и его сброс |

Захват и команды `gripper` в новый контракт не входят.

## Состояния от робота

| Область | Состояния |
| --- | --- |
| Ровер | `odometry`, `battery_state`, `rover_state` |
| Манипулятор | `joint_state`, `planning_state`, `execution_state` |
| Система | `fault_state`, состояние управления и доступность камер |

Для `cmd_vel` сервер ограничивает частоту и срок действия команды. При потере соединения или прекращении команд скорость задаётся нулевой на стороне робота. Значения суставов и лимиты берутся из новой модели, когда она будет предоставлена.

Перед реализацией аппаратного адаптера нужно сверить топики, action и service фактических пакетов управления. Этот документ не утверждает конкретные ROS-имена.
