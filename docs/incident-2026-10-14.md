## Продолжение: телеметрия восстановилась, команды не исполнялись

После перезапуска только gateway подключение UI восстановилось, но процессы
MoveIt, cmd_vel_stamper и аппаратные менеджеры ещё работали со старым DDS
профилем. Все ROS-процессы control-служб затем перезапущены с единым UDP-only
профилем. При чтении лимитов первоначальный запуск руки завершился ошибкой;
повторный запуск systemd прошёл успешно.

Проверка без ненулевой скорости: три нулевых Twist прошли через stamper и
были получены как TwistStamped. Реальное движение ровера требует проверки
оператором. Запрос MoveIt теперь получает ответ, однако текущая поза модели
отклонена CheckStartStateCollision: link_02 — link_05_red. Это отдельный отказ
планирования, который нельзя исправлять отключением проверки столкновений.

Для готовности arm gateway дополнительно требует обнаруженные сервис
планирования MoveIt и action FollowJointTrajectory. Готовность подключения
сама по себе не гарантирует допустимость текущей позы или каждой цели.
